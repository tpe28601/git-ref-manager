      功能說明
      
    
      
    
      
      
      本地同步（Repo A -> Repo B）
      
      
        
        
      • 只做本地 Ref 複製：不 push、不刪 ref、不動工作目錄與 HEAD。
        • 
        
      • 同步範圍看勾選：refs/remotes/origin/*、本地 Branch（備份到 refs/sync/source-heads/*）、Submodule 遞迴。
        • 
        
      • 兩段式：「預覽差異」-> 預覽結果內「執行同步」；改過選項要重新預覽。
        • 
        
      • 預覽結果預設全部收合：點目的 Repo 標題列看明細，合計列有「全部收合／全部展開」。
        • 
        
      • 一鍵同步：自動補驗證＋預覽，有差異直接套用。
        • 
        
      • 驗證燈：綠勾＝通過（點開看分支／origin 明細）、紅叉＝失敗；Enter＝強制重驗。
        • 
        
      • A 與 B 不能同路徑：與來源相同會彈窗提示並擋下；目的列彼此重複路徑者標記紅旗，需刪列或改路徑。
        • 
        
      • 衝突（D/F、大小寫重複）一律自動略過並回報，不硬覆蓋；大小寫重複每次預覽都會重現，屬正常。
        • 
        
      • A 與 B 的 origin 不同時要勾 forceOrigin 才執行；「一鍵同步」右側 force 勾選＝預先同意、不再彈窗。
        • 
        
      • Submodule 清單：來源驗證通過後出現，預設收合並顯示「已選／可處理／略過」；增減或更換目的 Repo 立即以已驗證資料重組清單，不會重複驗證；送出前另有輕量比對，工具外動過初始化會自動刷新。「從 A 初始化」（單一目的）以 A 的本機複製初始化 B 側，離線可用。
        • 
        
      • 設定檔（分頁列按鈕）：儲存／載入三個分頁的設定；重新開頁自動還原上次設定。
        • 
        
      • 工作面板不自動展開，看徽章：待機 -> 等待指令中 -> 進行中 -> 完成／失敗；收合時工作結束會亮小圓點。進行中也能看歷史紀錄（即時進度在背景更新）。
        • 
      
      
    
      
    
      
      
      Fetch Origin
      
      
        
        
      • 對 Repo 執行 git fetch origin，會實際連遠端，需二次確認。
        • 
        
      • B 可留空＝只 Fetch A；B 與 A 同一 Repository（Worktree）時自動略過。
        • 
        
      • --prune 只清遠端已刪除的 origin 追蹤分支，不動其他本地 ref。
        • 
        
      • 遞迴只 fetch 已初始化的 Submodule；單一 Repo 失敗不影響其他 Repo。
        • 
      
      
    
      
    
      
      
      Worktree
      
      
        
        
      • 在上層資料夾以 git worktree add 建新工作目錄並簽出新 Branch（名稱必填）。
        • 
        
      • 先「檢查」（來源是否為 Repo、目標不存在、Branch 不重複、可寫），全過才能「建立」。
        • 
        
      • 含 Submodule 時不會自動初始化，需要請自行 git submodule update --init。
        • 
        
      • 本工具只建立；移除請用 git worktree remove。
